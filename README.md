## 用法

1. 下载 `index.html`，双击用浏览器打开即可，全部计算在本机完成。
2. 顶部搜索框可按名称/关键词定位工具，快捷键 `Ctrl+F` 聚焦搜索。
3. 同族参数（管径、钢筋、电缆截面、型钢规格等）合并为规格下拉；一步式公式合并为 45 个「XX 速算」总汇，内置口径筛选框。
