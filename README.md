## 用法

1. 下载 `index.html`，双击用浏览器打开即可，全部计算在本机完成。
2. 卡片右上角星标可收藏，收藏与最近打开会置顶在首页；顶部按钮切换深浅色。
3. 顶部搜索框定位工具，支持别名（搜「卡路里」也能找到「食物热量」）；进入计算器后，先用专业横条筛选，再点口径下拉或在搜索框输入关键词（如「混凝土」「电流」「房贷」）。
4. 同族参数（管径、钢筋、电缆截面、型钢规格等）已合并为规格下拉，切换即换口径。
